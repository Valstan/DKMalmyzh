## Грабли этой сессии (не наступать снова)

- **Бокс делят несколько сайтов**; у гоньба.рф `listen 443 ssl default_server`. Проверка «curl -H Host → 200» ничего не доказывает — нужен контент-маркер («РЦКД»). Диагностика: `probe-nginx.yml` (read-only, `nginx -T`).
- **TLS терминирует сам nginx на боксе**, а не прокси Джино (это схема бокса Сабантуя — перенос её сюда и был первой ошибкой).
- ACME-webroot — в `/var/www`, не в домашнем каталоге (nginx-воркер туда не ходит, `try_files … =404` маскирует отказ под 404).
- На боксе **nginx 1.24**: `http2` — параметр `listen`, не отдельная директива.
