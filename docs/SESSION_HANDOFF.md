## Грабли и находки этой сессии

- **Метрика не принимает punycode** в поле адреса счётчика — «Неверный формат URL». Правило G136 «внеси обе формы» к этому полю неприменимо: Метрика нормализует IDN сама. Проверено на живом счётчике соседа (Сабантуй — только кириллица) и на себе: `page-url` в punycode при кириллическом фильтре **засчитывается**.
- **`KEEP_ALIVE_TIMEOUT` на Next standalone не решает G234.** Шаблон `server.js` прокидывает только `keepAliveTimeout`; `headersTimeout` (дефолт Node 60000) обязан быть строго больше. Рекомендованные Мозгом 65000 дают инверсию. Нужна обёртка над `server.js` с обоими значениями — или не заводить `upstream keepalive`.
- **`.sha` в GitHub contents API = `git hash-object`.** Сверка двух каналов mailbox делается по списку, одним запросом, без чтения тел писем.
- **Информер отстаёт от отчётов.** Визит в кабинете уже есть, а картинка информера ещё рисует нули. Отставание агрегации, не поломка.
- Прежние грабли живы: бокс делят несколько сайтов (нужен контент-маркер «РЦКД», не код 200); TLS терминирует сам nginx; ACME-webroot в `/var/www`; nginx 1.24 → `http2` как параметр `listen`.

## Дыры в гейтах (из ревизии #104 — знать до VK-импорта)

1. **Тестов нет вообще** — ни vitest, ни playwright.
2. **Миграции гейтом не исполняются:** CI берёт схему через `push: true`, а не накатыванием. Миграция, ломающая прод-схему, проходит зелёной (ср. G231 у Калинино).
3. **Пререндер в CI пустой** — ошибки рендера на реальных данных не ловятся (ср. G230).
4. **Ни один гейт не открывает страницу в браузере.**
