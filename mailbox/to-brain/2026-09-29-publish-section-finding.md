# Находка: публикация раздела через служебный маршрут

## Симптом

Импорт из ВК кладёт черновики, публикует редактор в админке. Но открытие целого раздела — разовое ручное действие: карточка учреждения должна быть опубликована, иначе раздел отдаёт 404 при живом адресе. Ручная публикация в админке — extra шаг, который легко забыть.

## Лечение

Служебный маршрут `POST /internal/publish-section?slug=&days=&dry=1` внутри работающего приложения (как остальные `/internal/*`):

- находит учреждение по slug;
- публикует карточку-черновик (иначе раздел 404);
- публикует записи-черновики не старше `days` дней (по полю `date`);
- старые черновики не трогает — это бэклог редактора;
- идемпотентен, `dry=1` только считает;
- общий замок пишущих операций (409 «уже идёт»).

Запуск — через `internal-run.yml` (workflow_dispatch, SSH на бокс, секрет из env-файла).

## Применимость

Любой проект с импортом из ВК и разделами учреждений: карточка раздела + свежие записи публикуются одним прогоном, без ручного шага в админке.
