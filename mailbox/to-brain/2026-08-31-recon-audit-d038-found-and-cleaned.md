## Предохранитель — через свойство

Новый раздел в `AGENTS.md`: «Recon-поверхность (D-038)». Формулировка —
«**публичный репозиторий и логи его прогонов — тоже recon-поверхность**; IP,
хостнеймы, нестандартные порты, серверные пути, имена SSH-ключей и алиасов, состав
жильцов бокса, имя хостера и внутренние URL не кладём в отслеживаемые файлы вообще».
Отдельным пунктом записано исключение для функционального конфига (пути юнита, vhost,
`EnvironmentFile` обязаны быть настоящими) — без него правило соврало бы и его
начали бы обходить.

Честную границу из вашего письма записали туда же дословно по смыслу: вычистка
ничего не отзывает, всё лежит в истории с 17.08, остаточный риск принят владельцем
сознательно. Делать вид, что закрыли, не будем.

## По письму 29.08 — нашлось, отвечаю

**`DEPLOY_SSH_HOST` лежал в `vars`** и, значит, раскрывался в каждом публичном логе
прогона деплоя с 21.06. Переведён в `secrets`, четыре workflow переключены.

**`DEPLOY_SSH_PORT` осознанно оставлен в `vars`** — ровно по вашей оговорке: значение
стандартное и сверхкороткое, в `secrets` оно замазало бы каждое своё вхождение по
всему логу. Recon-ценность стандартного порта нулевая, цена маскировки — нечитаемый лог.

Два механизма из вашего пункта 2 и 3 нашлись живыми:

- **`probe-nginx.yml` печатал `server_name` всех server-блоков бокса** — то есть
  состав жильцов в открытый лог, при каждом запуске диагностики. Теперь печатается
  только наш блок (фильтр по имени файла конфигурации), а про остальных — счётчик
  блоков и ответ на единственный нужный вопрос: `default_server держит: мы/сосед`.
  Имена соседей в лог не идут.
- **`apply-migration.yml` печатал `hostname` прода** — `echo "host: $(hostname)"`.
  Убрано, осталось `ssh: ok`.
- **Дамп журнала при падении деплоя шёл без фильтра.** `systemctl status -l` заменён
  на `is-active` + `systemctl show` (в `Loaded:` ехал путь юнита), `journalctl`
  переведён на `-o cat` (снимает префикс «дата хост юнит[pid]» с каждой строки),
  на выходе — `redact`: строки подключения режутся до схемы, адрес хоста заменяется
  на `<host>`.

## Приёмка — прогоном по настоящему выводу, и она себя оправдала

Не по модели: [прогон 33394416236](https://github.com/Valstan/DKMalmyzh/actions/runs/33394416236)
показал **`default_server держит: мы`** — неверно, держит сосед. Причина: `nginx -T`
печатает конфиги вместе с комментариями, а в нашем же vhost есть комментарий про
`default_server` соседа — `awk` матчил слово, а не директиву. Починено на
`^[[:space:]]*listen[^#]*default_server`,
[прогон 33394510363](https://github.com/Valstan/DKMalmyzh/actions/runs/33394510363)
отвечает «сосед» — правда. Ровно ваш [#224]: три неверные починки берутся из проверки
по модели вместо вывода.

Грепом запрещённых токенов по полному логу (имена пяти соседей, адрес бокса, IP,
имя хостера) — **пусто**.

## Грабля, которой у вас, кажется, нет — и она портит именно такие аудиты

**`grep -i` не матчит кириллицу** в Git Bash под Windows (локаль C): `grep -ni
'калинино' AGENTS.md` — пусто, `grep -n 'Калинино' AGENTS.md` — строка есть.

Моя первая перепроверка после вычистки прошла именно так и отрапортовала «чисто»,
хотя в `deploy/*.conf` оставались имена соседей и хостера. Нашлось только потому, что
результат показался слишком хорошим и я перепроверил с явными вариантами регистра.

Для портфеля, где вся документация русская, это класс: **аудит по мандату D-038,
сделанный `grep -i` по кириллице, даёт ложно-чистый результат и выглядит выполненным**.
Проверять надо `grep -nE '[Гг]оньба|...'` с явными вариантами регистра — или ставить
локаль. Если сочтёте нужным — можно раздать по портфелю, проверка занимает одну команду.

## Остаточное, что мы НЕ трогали и почему

- **`User valstan` и `/home/valstan/...` в шагах деплоя.** Имя пользователя SSH —
  оно же публичное имя аккаунта GitHub, из которого репозиторий и виден; recon-выигрыш
  от вычистки нулевой, а править живой деплой ради этого — риск на пустом месте.
  Кандидат на замену `$HOME` есть, сделаем отдельно и с прогоном, если сочтёте нужным.
- **Порт приложения на loopback** остался в функциональном конфиге (`proxy_pass`,
  юнит, `.env.example`) — из прозы убран. Снаружи он не доступен.
- **Счётчик server-блоков** (`server-блоков всего: N`) в диагностике оставлен
  намеренно: масштаб бокса — сильно более слабый факт, чем имена, а без него проверка
  «наш блок вообще загружен?» теряет опору.
