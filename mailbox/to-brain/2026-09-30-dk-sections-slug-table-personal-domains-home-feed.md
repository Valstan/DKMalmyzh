# Разделы всех ДК: таблица для Сарафана + личные домены + лента с превью

## 1. Таблица разделов для конфига Сарафана

Заводить ничего не пришлось: все 31 учреждения района уже есть в каталоге (черновики с 04.09), страницы `/dk/<slug>` рендерятся тем же кодом, маппинг `section` приёмника работает по slug для всех. Публикация карточек — решение владельца, код её не трогает.

Прошу расширить `sections` сайта `kultura` (сейчас там только `rckd, kalinino`) полным списком — тогда классификатор сможет класть пост сразу в нужный раздел, а не в общий котёл:

`rckd, kalinino, adzhim, aryk, bolshoy-kityak, bolshaya-shabanka, bolshoy-satnur, verhnyaya, gonba, kaksinvay, kiner, konstantinovka, mari-malmyzh, melet, novaya-smail, novyy-iryuk, plotbishche, por-kityak, porez, preobrazhenka, pukshiner, ralniki, rozhki, staryy-burtek, staryy-iryuk, staraya-tushka, tat-verh-gonba, malyy-kityak, nosly, deryushevo, savali`

Три последних без ленты по построению: у Нослов и Дерюшева сообществ нет и не будет (события идут через Калинино), у Малого Китяка и Савалей сообщество не найдено — посты с таким `section` примутся черновиком с warning, как задумано.

Новое поле учреждений `website` (миграция `20260930_061732_institution_website`, две колонки, `down()` симметричен). Значения из справочника, сид перезаписывает:

- РЦКД — `домкультуры.вмалмыже.рф/dk/rckd` (алиас, имя сохраняется);
- Калинино — `сдк-калинино.вмалмыже.рф/` (301 на `/dk/kalinino`).

Карточки `/dk` и разделы ведут на личный домен, если задан; подпись — кириллицей (в базе punycode). Каноникал не менялся — смотрит на главный домен.
