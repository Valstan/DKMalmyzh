# Все черновики опубликованы, все 31 раздел открыты

Заказ владельца 30.09: опубликовать всё накопленное, дату публикации поставить как в оригинале, разнести по домам культуры, и чтобы дома появились в списке на портале с ссылкой на свой раздел.

**Новая операция:** `POST /internal/publish-all` (`?dry=1`), запуск — `internal-run.yml`, операция `publish-all` (обычный и сухой прогон). Ядро — `web/src/lib/sections/publishAll.ts` + 11 юнитов, гейт — `scripts/publish-all-selftest.ts` в `gates` (после e2e: операция публикует все черновики базы, включая сидовые для негативных e2e-проверок).

**Что делает боевой прогон:** публикует все карточки и все записи, `publishedAt` = `date` (дата оригинала); уже опубликованным правит только дату; записи без дома пристраивает по владельцу стены (`vkUid` → `ownerId`), затем по упоминанию короткого названия в тексте (префикс по словам, все токены обязательны, побеждает самый длинный стем; неоднозначность — в отчёт, не к чужому дому). Пишет с `disableRevalidate` и один раз сбрасывает кэш ключевых страниц — единственный vCPU не терпит сотни сбросов.

**Прогон на проде (сухой, затем боевой):** карточек опубликовано 29 (2 были — РЦКД и Калинино), записей 725, дат поправлено уже опубликованным 26, без дома 0, без даты 0, ошибок 0. Сверка снаружи: публичный API — 973 записи и 31 учреждение, `/dk` — 31 карточка, все 29 разделов внутренними адресами отдают 200, корень личных доменов ведёт куда надо (РЦКД 301 → `/dk/rckd`, Калинино 301 → `/dk/kalinino`), sitemap 1008 адресов, дата публикации = дата оригинала на выборке.

**Решение владельца по спорным карточкам:** публикуем все 31, включая Нослы и Дерюшево — их заметки справочника от 01.09 («раздел останется без ленты — не публиковать, если это не нужно») решением 30.09 перекрыты. Пустых разделов ровно три: Нослы, Дерюшево, Малый Китяк (у последнего в справочнике «сообщество ВК не найдено»). Откат — одна кнопка в админке.

**Что это значит для конвейера:** политика не изменилась — приёмник по-прежнему кладёт **черновики**, публикует редактор. Просто стартовая база больше не пустая: на сайте уже 973 записи, и новые доставки Сарафана будут приходить в уже открытые разделы.
