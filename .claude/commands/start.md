Выполни старт сессии «ДК Малмыж» строго по шагам (детали — в `AGENTS.md` §📬 Mailbox). Порядок жёсткий: **сначала синхронизация только своего репозитория, затем двойное read-only чтение mailbox, потом session-память** — pool #032.

1. **Sync свой репо — ПЕРВЫМ и ЕДИНСТВЕННЫМ:** `git fetch`; если working tree чист и есть отставание — `git checkout main && git pull --ff-only`. Незакоммиченное / не-ff — сообщи и не форсируй.
2. **Brain и соседние репо не синхронизировать:** не выполнять в `../brain_matrica/` и других чужих репозиториях `fetch`, `pull`, `checkout` или любые изменяющие команды. Там прямо сейчас может работать владелец или другой агент — в том числе с ещё не запушенной почтой.
3. **Скан входящих из двух read-only источников:**
   - локально — корень `../brain_matrica/mailboxes/DKMalmyzh/from-brain/*.md`;
   - через GitHub API/веб — `main:mailboxes/DKMalmyzh/from-brain/*.md` репозитория `brain_matrica`, **без clone/fetch/pull**;
   - НЕ читать `DRAFTS/` и `ARCHIVE/`; набор писем — объединение источников по относительному пути;
   - одинаковые версии читать один раз; содержимое различается — свежесть по истории **этого файла**, а не репозитория: незакоммиченная локальная версия — более свежий кандидат, иначе последний локальный коммит файла vs последний коммит этого пути на GitHub;
   - порядок надёжно не определяется — прочитать обе версии и явно доложить конфликт. Ничего не копировать и не перезаписывать.
   - Клон/канал недоступен — так и доложи. «Новых писем нет» законно только когда проверены **оба** канала.

   Второй канал (проверено 2026-08-10) — список писем и blob-SHA без клонирования:
   ```bash
   gh api "repos/Valstan/brain_matrica/contents/mailboxes/DKMalmyzh/from-brain?ref=main" \
     --jq '.[] | select(.type=="file") | "\(.sha)  \(.name)"'
   ```
   SHA здесь — это `git hash-object` файла, поэтому расхождение содержимого ловится сверкой с `git hash-object` локальных файлов, без чтения тел. Совпали — читать только локальные; разошлись — тело с GitHub берётся `gh api ... -H "Accept: application/vnd.github.raw"`.

   `urgency: high` выдели отдельно. Письма без `compliance`: `kind: directive`→MUST, `kind: idea`→SHOULD.
5. **Прочитай** `docs/SESSION_HANDOFF.md` — статус, нитка, следующий шаг. Если `Updated:` старше 14 дней — пометь «может быть неактуально».
